# Проверка вакансий Job HI-TECH × Makler

Одностраничный сервис для ручной проверки открытых вакансий. Кнопка на странице запускает Cloudflare Worker, который:

1. получает список вакансий с [job.hi-tech.md](https://job.hi-tech.md/) и открывает каждую карточку;
2. получает объявления пользователя `1262205` с Makler через публичный список, проходит все страницы пагинации и открывает каждое объявление;
3. извлекает текст, город, ссылку и дату публикации Makler;
4. передаёт оба набора данных и инструкции редактора в DeepSeek;
5. показывает новый структурированный отчёт в браузере. Ничего не сохраняется.

В отчёте предусмотрены категории: противоречия, несоответствия, неполные данные, орфография/стиль, объявления только на одном сайте и объявления Makler старше 12 дней. Ссылки на исходные вакансии выводятся в каждой карточке замечания.

## Локальный запуск

Нужны Node.js 20+ и аккаунт Cloudflare.

```powershell
npm install
Copy-Item .dev.vars.example .dev.vars
# Укажите ключ DeepSeek в .dev.vars
npm run dev
```

Откройте адрес, который выведет Wrangler. Ключ никогда не попадает в браузер: Worker вызывает DeepSeek со стороны сервера.

## Развёртывание в Cloudflare

1. Войдите в Cloudflare: `npx wrangler login`.
2. Переименуйте проект в поле `name` файла `wrangler.toml`, если это имя уже занято.
3. Добавьте обязательный секрет:

   ```powershell
   npx wrangler secret put DEEPSEEK_API_KEY
   ```

4. Необязательно добавьте свой редакторский промпт — он заменит базовую инструкцию:

   ```powershell
   npx wrangler secret put ANALYSIS_PROMPT
   ```

5. Выполните `npm run deploy`.

После этого Wrangler выведет публичный `workers.dev` URL. Его можно открыть без авторизации с компьютера или телефона. Позже этот Worker можно привязать к своему домену в панели Cloudflare.

## Настройки

| Переменная | Назначение |
| --- | --- |
| `DEEPSEEK_API_KEY` | Обязательный секрет API DeepSeek. |
| `ANALYSIS_PROMPT` | Необязательный секрет с внутренними правилами проверки. |
| `DEEPSEEK_MODEL` | Модель, по умолчанию `deepseek-chat`. |
| `MAX_MAKLER_PAGES` | Предохранитель количества страниц Makler, по умолчанию 10. |
| `STALE_AFTER_DAYS` | Порог давности публикации Makler, по умолчанию 12 дней. Можно поставить `10`, если нужен ранний вариант правила. |

`DEEPSEEK_MODEL` и `MAX_MAKLER_PAGES` можно менять как Variables в панели Cloudflare или в `wrangler.toml`. Секреты не коммитятся.

## Важные эксплуатационные замечания

Сервис публичный, однако каждый запуск расходует запросы к DeepSeek. Перед публикацией рекомендуется создать в Cloudflare WAF Rate Limiting rule для `POST /api/check` (например, 2 запуска с одного IP за 10 минут). Это не меняет доступность страницы, но защищает бюджет API. При изменении разметки сайтов селекторы находятся в `src/worker.ts`.
